# NETPBM-image-editor

Made for the BME programming 1 course homework - BME Programozás alapjai 1 nagy házi feladat.

# About the software
It is a basic command line tool to edit a NETPBM image.
The program can open every [NETPBM](https://en.wikipedia.org/wiki/Netpbm) image formats: PPM, PBM and PGM.

The tool can do these modifications with the image:
- The brightness
- The contrast
- Add blurring
- Create a grayscale version of the image
- Make the image binary black and white
